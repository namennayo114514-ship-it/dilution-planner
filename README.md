# 希釈プランナー

Qubitで求めた原液のRNA濃度から、各サンプルの最終調製量を計算するブラウザアプリです。
初期画面には1〜50 ng/µLの仮データ60件が入っています。目標は初期値で13 µL・1 ngです。

## 使い方

1. 最終体積、目標量、P2・P10・P20・P200の最小・最大分注量と分注刻みを設定します。
2. CSVまたはタブ区切りの表を貼り付けます。列は `id,rna,dna,stock` の順です。
   DNA濃度と原液残量は任意です。DNA濃度はCSVに記録され、RNA調製の計算にはRNA濃度を使います。
   濃度は原液の ng/µL、原液残量はQubit測定後に使える µL で入力します。
3. 計算し、各サンプルの中間チューブと最終チューブの欄を確認します。印刷とCSV保存ができます。

初期値は Gilson PIPETMAN の表示桁で合わせやすい刻みを採用しています。使用機種の設定に合わせて変更できます。

| ピペット | 範囲（µL） | 刻み（µL） |
| --- | ---: | ---: |
| P2 | 0.2–2 | 0.01 |
| P10 | 1–10 | 0.1 |
| P20 | 2–20 | 0.1 |
| P200 | 20–200 | 1 |

各体積は1回で設定できる値から選び、操作表とCSVにピペット名を表示します。
水量の集計には中間チューブ用と最終チューブ用の内訳を表示します。
節水のため、共通移送量の初期値はP2の0.20 µLです。使用するピペットで量り取れる体積に変更できます。

## 調製候補の選び方

- 指定の分注範囲・刻み・許容差に収まる直接調製を優先します。
- 中間希釈が必要な場合は、指定した共通移送量を優先します。その条件で、各サンプルの中間用と最終用を合わせた水量を最小化します。同じ水量なら原液使用量の少ない候補を優先します。
- 共通移送量で成立しないときは個別の移送量を探索します。最大1段の中間希釈で成立しない条件は「要確認」と表示します。
- 中間チューブには、移送する量に加えて設定した余裕量を確保します。原液残量が入力されていればその上限も守ります。
- RNA見込み量は設定体積に基づく理論値です。中間液の余裕0.5 µLと許容差2%は試用設定です。

`index.html` をブラウザで直接開くか、GitHub Pagesで使用できます。入力はブラウザ内で処理します。再読み込みすると仮データに戻ります。
